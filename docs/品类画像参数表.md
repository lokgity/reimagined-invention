# 品类画像参数表（4 品类）

> 评分引擎采用"1 套通用框架 + 4 份品类画像参数"。
> 通用框架：客群匹配度 / 竞争压力 / 交通可达性 / 租金承受力（各 0~100 分）
> 本表定义每个品类：目标客群关键词、维度权重、参考半径、竞争基准、经济模型参数。

---

## 设计原则

1. **参数必须有出处**：每个权重/基准尽量引用可查证的经济学原理或行业常识，答辩能说清"为什么这么定"。
2. **数据可得性优先**：只依赖高德 POI 能拿到的数据（学校/写字楼/小区/商场/地铁站/竞品密度），不依赖拿不到的真实人流。
3. **不承诺营业额**：评分是"相对选址适宜度"，不是"预测营收"。
4. **承认局限**：输出必须声明"基于公开 POI 数据，未包含真实人流量/租金成交数据"。

## 一、奶茶（新式茶饮）

### 1. 画像一句话
**高客流年轻客群驱动的冲动型消费**：核心是"路过的人对不对"，不是"住在周围的人多不多"。

### 2. 目标客群 POI（客群匹配度证据）
| 客群类型 | 权重 | POI 关键词（高德） |
|---|---|---|
| 学校（大学为主） | 0.35 | 大学、学院、职业技术学院 |
| 写字楼/办公 | 0.25 | 写字楼、商务大厦、产业园 |
| 商业中心 | 0.20 | 购物中心、商场、商业街、步行街 |
| 小区（年轻社区） | 0.20 | 小区、公寓（注：作为补充，不主导） |

### 3. 维度权重
| 维度 | 权重 | 理由 |
|---|---|---|
| 客群匹配度 | 0.35 | 奶茶是客群驱动型消费，人对了才卖得动 |
| 竞争压力 | 0.25 | 奶茶同质化严重，密度敏感 |
| 交通可达性 | 0.25 | 依赖"路过客流"，动线决定曝光 |
| 租金承受力 | 0.15 | 客单价低(¥12-20)，租金敏感度极高 |

### 4. 参数
- 参考半径：**500m**（奶茶消费决策半径短，属于即时性消费）
- 竞争基准：500m 内同类 **≥8 家** 判为饱和（参考：头部品牌同商圈加密至 10+ 家视为过度）
- 客单价参考：¥12~20
- 盈亏平衡参考：月租 < 预估月流水 × 12%（粗估，用于租金维度计算）

### 5. 经济学依据
- 冲动型消费 + 短决策半径 → 中心地理论中的"低门槛商品高频次消费"，应靠近消费热点
- Huff 引力模型：奶茶店吸引力随距离衰减快，故参考半径取小值

## 二、甜品（蛋糕/甜品店/糖水铺）

### 1. 画像一句话
**目的性+场景性消费**：消费者是"专门去买"，不是"路过顺手买"，选址看重可达性和商圈氛围，对竞争相对不那么敏感（差异化空间大）。

### 2. 目标客群 POI
| 客群类型 | 权重 | POI 关键词 |
|---|---|---|
| 商业中心/商圈 | 0.30 | 购物中心、商场、商业街、步行街 |
| 写字楼/办公 | 0.25 | 写字楼、商务大厦 |
| 学校 | 0.20 | 大学、中学、学院 |
| 中高档小区 | 0.25 | 小区（偏向改善型社区） |

### 3. 维度权重
| 维度 | 权重 | 理由 |
|---|---|---|
| 客群匹配度 | 0.35 | 目的性消费仍需客群基础 |
| 交通可达性 | 0.25 | 专程前往 → 可达性权重高于奶茶 |
| 竞争压力 | 0.20 | 甜品差异化空间大，密度敏感度低于奶茶 |
| 租金承受力 | 0.20 | 客单价较高(¥20-40)，租金承受力强于奶茶 |

### 4. 参数
- 参考半径：**800m**（目的性消费，半径大于奶茶）
- 竞争基准：800m 内同类 **≥6 家** 判为饱和（甜品店密度天然低于奶茶）
- 客单价参考：¥20~40
- 盈亏平衡参考：月租 < 预估月流水 × 15%

### 5. 经济学依据
- 目的性消费 → 中心地理论中"较高门槛商品"，服务半径更大，更看重可达性而非纯客流
- 消费场景与"仪式感/社交"相关 → 贴近商圈和改善型社区

## 三、早餐（早点/包子/煎饼/肠粉等）

### 1. 画像一句话
**高频、低价、极短决策时间、刚需**：靠"通勤路上正好路过"，时效性极强，竞争看"同品类密度"，选址本质是"抢动线"。

### 2. 目标客群 POI
| 客群类型 | 权重 | POI 关键词 |
|---|---|---|
| 地铁站/公交站（通勤） | 0.40 | 地铁站、公交站 |
| 写字楼/办公 | 0.30 | 写字楼、商务大厦、产业园 |
| 小区（居住密度） | 0.30 | 小区、公寓、住宅区 |

### 3. 维度权重
| 维度 | 权重 | 理由 |
|---|---|---|
| 交通可达性 | 0.35 | 早餐靠通勤动线，位置即一切 |
| 客群匹配度 | 0.30 | 上班族/学生是刚需主力 |
| 竞争压力 | 0.20 | 早餐同质化，但单店辐射范围小 |
| 租金承受力 | 0.15 | 客单价极低(¥5-15)，租金敏感度最高 |

### 4. 参数
- 参考半径：**300m**（极短决策半径，主要覆盖"门口路过"）
- 竞争基准：300m 内同类 **≥5 家** 判为饱和
- 客单价参考：¥5~15
- 盈亏平衡参考：月租 < 预估月流水 × 10%（毛利高但单量刚性）

### 5. 经济学依据
- 极高频 + 极低门槛 → 中心地理论最低门槛商品，服务半径最小
- 需求刚性 → 选址核心是"动线曝光"，不是"客群丰富度"

## 四、便利店

### 1. 画像一句话
**居住/办公密度驱动的高频复购**：靠"常住人口和办公人口"支撑，24h 属性强，竞争看"品牌密度"，选址看"人口基数"而非"热闹"。

### 2. 目标客群 POI
| 客群类型 | 权重 | POI 关键词 |
|---|---|---|
| 小区（居住密度） | 0.40 | 小区、公寓、住宅区、社区 |
| 写字楼/办公 | 0.30 | 写字楼、商务大厦、产业园 |
| 学校 | 0.15 | 大学、学院、中学 |
| 地铁站 | 0.15 | 地铁站、公交站 |

### 3. 维度权重
| 维度 | 权重 | 理由 |
|---|---|---|
| 客群匹配度 | 0.40 | 便利店是人口基数生意 |
| 竞争压力 | 0.25 | 品牌连锁密集区（罗森/全家/美宜佳）需避开 |
| 交通可达性 | 0.20 | 需要好到达，但不是"路过冲动"逻辑 |
| 租金承受力 | 0.15 | 毛利高(25-35%)，租金承受力较好 |

### 4. 参数
- 参考半径：**500m**（高频复购，但覆盖常住人口）
- 竞争基准：500m 内同类 **≥4 家** 判为饱和（含连锁品牌）
- 客单价参考：¥10~20
- 盈亏平衡参考：月租 < 预估月流水 × 20%

### 5. 经济学依据
- 高频低值 + 强复购 → 靠"人口基数×复购频次"，贴近居住/办公密度
- 24h 属性 → 夜间人口同样重要（小区/公寓权重高）

## 五、通用评分规则（v2：Huff 引力模型版）

> 评分引擎已从"POI 计数"升级为 **Huff 引力模型**（详见代码 `src/engine/scoring.py`）。

### 0. Huff 引力核心

对任意 POI 集合，引力累计：

```
G = Σ ( 1 / (d_i + d0) )^λ
```

- d_i = 该 POI 到候选地址的距离（米）
- d0 = 50m 最小等效距离（避免除零，模拟到店距离）
- λ = 2.0 距离衰减参数（Huff 文献常用值，答辩说明为有依据的估计）

**核心思想（Reilly/Huff）**：距离越近的客群或竞品，影响力越大——"店门口 50 米的学校"与"500 米边缘的学校"权重差异显著，而非传统计数法的一视同仁。

### 1. 总分 = Σ(维度分 × 权重)，各维度分计算：

**客群匹配度（Huff 引力版）**：参考半径内目标客群 POI 的距离衰减引力累计
- 对每类客群（学校/办公/商圈/社区/通勤）：G = Σ(1/(d+50))^2，再按品类客群权重加权
- 归一化：参考配置 = 30 个客群点均匀分布在 0.5×radius 处 → 100 分
- 意义：越近、越多的匹配客群 → 高分；远处客群贡献指数级衰减

**竞争压力（Huff 引力版）**：竞品引力累计 vs 参考配置
- 参考配置：comp_base 家竞品均匀分布在 0.5×radius 处（中等竞争，≈60 分）
- 引力比 r = G_实际 / G_参考：r=0.5→90分，r=1.0→60分，r=1.5→30分，r≥2.0→0分
- 意义：竞品越近越密集，引力比越高，扣分越狠（比单纯数数量更贴近真实竞争强度）

**交通可达性**：最近地铁站距离 + 公交站密度（保持简化）
- ≤300m 地铁 → 90+；300~800m → 70~90；800~1500m → 40~70；>1500m → 40 以下
- 500m 内公交站密度加分（最多 +10）

**租金承受力**：用户输入月租 R，参考月流水 S（品类客单价 × 预估单量 × 30）
- R/S < 60%×limit → 90+；~limit → 70~90；~1.67×limit → 40~70；更高 → 40 以下
- 预估单量为品类基准粗估，明确标注为估算

### 2. 结论规则
- 总分 ≥ 75 → "推荐"
- 60~74 → "谨慎推荐"（列出风险点）
- 45~59 → "不建议优先选择"
- < 45 → "不建议"

### 3. 主动质疑触发规则（Agent 层）
- 竞争压力 < 30 分 → 必警告："该位置同品类已饱和"（引用竞品引力比）
- 客群匹配度 < 40 且竞争压力 < 40 → 提示品类错配
- 租金承受力 < 40 → 必警告盈亏风险
- 目标客群引力累计为 0 → 提示"数据稀疏，建议人工复核"

## 六、参数出处与局限声明（答辩用）

- **模型依据（已实现）**：Huff 引力模型（Huff, 1963）、Reilly 零售引力法则（1931）、中心地理论（Christaller），权重结合品类消费行为常识
- **λ 参数**：取 Huff 文献常用值 λ=2，属于有依据的估计，未用真实交易数据校准
- **竞争基准**：参考头部品牌门店加密密度与行业报告量级（如中国连锁经营协会便利店报告），为**量级估计**
- **明确局限**：所有分析基于公开 POI 数据，不含真实人流量、成交租金、营业额；输出为"选址适宜度相对评分"，非营收预测
- 免责声明在界面和输出中均需展示，防评委挑战数据精度
