## 一、结论先行：原方案的第 1 步设计是错的，已修正

我第一版方案设计了一个"带约束 OLS 检验 四维度分 → 总分 的权重"，并预期它能给出 Wald 检验结论。**实测把这个设计证伪了**：

```
维度               OLS β      声明 w           差
客群匹配度         0.350359    0.3500   +3.59e-04
竞争压力          0.250292    0.2500   +2.92e-04
交通可达性         0.250231    0.2500   +2.31e-04
租金承受力         0.149301    0.1500   -6.99e-04
R² = 0.9999852189
```

β 精确复原声明权重，R² ≡ 1。原因在 `scoring.py`：

```python
total = Σ(dim_score × weight)     # 无截距加权和
```

**总分就是四维度分的线性组合。用 OLS 去"检验"它，等于用回归去验证一个定义式**——必然得到 β≡w、R²≡1，不含任何数据证据。把它报成"回归验证了权重"，是把定义式当发现，答辩时一问就穿。

**这个坑值得写进文档**，因为它正是"为了做回归而做回归"的典型陷阱。

## 二、修正后的框架：三层递进，各司其职

```
[1a] 恒等式核查  →  证明"四维度分→总分"是定义式，不可作为效度证据（负向结论）
[1b] 维度分自洽性 →  检验维度分与上游位置变量的方向是否合理（唯一有信息量）
[1c] 权重支持度  →  客观赋权能否支持手拍权重（方向性参考）
[2]  回归诊断    →  单变量对应的系数 + BP/JB 诊断
[3]  λ 参数估计  →  log-log 反解 λ 的 95%CI（参数敏感性参考，非效度）
```

### [1b] 为什么这才是唯一有信息量的检验

维度分**不是**恒等式产物——它是位置变量的函数。检验方法：

| 维度 | 上游变量 | 预期方向 | 实测 Pearson | 结论 |
|---|---|---|---|---|
| 客群匹配度 | 需求规模 D | 正 | **+0.5259** | ✅ p<0.001 |
| 竞争压力 | 捕获份额 P | 正 | **+0.8834** | ✅ p<0.001 |
| 交通可达性 | 最近同类距离 | 负 | −0.0532 | ✅ ns |

三条全部方向正确。**"竞争压力 ↔ 捕获份额 = +0.8834" 是这份分析里最有力的一个数**——它直接印证了 `scoring.py:161` 的 `s = 60.0 * P / p_ref` 在实测数据上成立。

## 三、实测数据发现的第二个坑：suppression

`D` 与 `P` 实测 `corr = −0.5111`。

原因很直觉：**需求密集的地方竞品同样密集，份额被摊薄**。

后果：如果把 `D` 和 `P` 同时放进一个回归去解释竞争压力：

| 模型 | β(P) | β(D) |
|---|---|---|
| 单变量 `竞争压力 ~ P` | **+82.17** | — |
| 双变量 `竞争压力 ~ P + D` | +82.17 | −0.42 |
| 单变量 `客群匹配度 ~ P` | **−63.84** | — |
| 双变量 `客群匹配度 ~ P + D` | −49.10 | +0.88 |

从 **+82.17 掉到 −49.10**（换个因变量），符号直接翻转。这就是 suppression。

**结论：每个维度只对其对应的上游变量做单变量回归，禁止混放。** 脚本里已经把这条写进注释和输出。

## 五、答辩口径（三种情况，直接可用）

### 情况 A：被问"你的权重怎么验证的"

> 「我们没有用回归去验证权重。因为总分的定义就是四维度分的加权和（`scoring.py` 无截距加权和），用 OLS 去回归它必然得到 β≡w、R²≡1——这是定义式的算术结果，不是数据证据。把它报成'回归验证了权重'是伪严谨。
>
> 我们做的是**维度分自洽性检验**：检验每个维度分与其上游位置变量的关系方向是否符合模型设定。实测三条全部通过，其中竞争压力与捕获份额的相关系数达 **+0.883**，直接印证了 Huff 份额映射在真实数据上成立。」

### 情况 B：被问"你做了什么回归"

> 「做了单变量线性回归 + 完整诊断。三个维度分别对其上游变量回归，系数与诊断报告如下（给出 [2] 节表格）。所有模型用 HC3 异方差稳健标准误，因为 BP 检验拒绝了同方差。
>
> 我们**没有**做多变量混放，因为 D 与 P 实测相关系数 −0.511（需求密集处竞品也密集），混放会产生 suppression 导致符号翻转——我们实测到 β(P) 会从 +82 翻到 −49。这是刻意规避，不是遗漏。」

### 情况 C：被问"为什么不验证模型能预测营收"

> 「因为因变量不成立。我们用'外卖月售'作经营代理做过检验，实测与模型核心预测子 P 的相关是 **−0.229（p=0.037）**，方向与预期相反；与其他变量全部不显著（p=0.10~0.77）。
>
> 在这个前提下做'选址分 → 营收'的回归，等于拿一个已被自己证伪的因变量去拟合模型。所以我们不做，而是把它明确列为**后续数据扩充计划**：需要补真实营业额（窄门餐眼）或成交租金（58同城）后才能做对外效度检验。」

## 六、λ 的参数估计结果（诚实呈现）

log-log 形式反解：

```
log(月售) = 10.0819 + 0.5469·log(1/(d+50)) + 0.6549·log(S)
           (p<0.001)   (p=0.0063)              (p=0.0282)
R² = 0.2184,  n = 83
λ 点估计 = 0.5469，95%CI = [0.165, 0.929]
```

**⚠️ CI 不覆盖文献值 2.0。**

这个结果**必须诚实报告**，并且有现成的解释：

> 「log-log 形式反解出的λ是 0.55，95%CI 不覆盖 2.0。但这个式子与 `scoring.py` 的 Huff 形式不完全等价——引擎式是 `P = (S/d0^λ) / (S/d0^λ + ΣS_k/(d_k+d0)^λ)`，含竞争项求和；log-log 里我只有一个距离弹性，是近似解读。
>
> 更关键的是，这个回归的因变量仍是外卖月售。我们已用 λ∈[1.0,3.0] 的**敏感性检验**证明结论不依赖 λ 的精确取值：全区间两两排名 Spearman 最低 0.937，Top10 重合度 ≥80%。所以 λ=2.0 取文献值是**稳健性声明**，不是参数标定。

**敏感性检验的数据（已有，来自 `_sens_out.txt`）**：

| λ 对比 | 排名 Spearman | Top10 重合 | Bottom10 重合 |
|---|---|---|---|
| 2.0 vs 1.0 | 0.968 | 80% | 80% |
| 2.0 vs 2.5 | 0.995 | 90% | 100% |
| 2.0 vs 3.0 | 0.986 | 90% | 90% |

这是**比回归更有说服力的证据**——它直接回答了"λ 取值会不会影响结论"。

# 第二部分：竞争压力映射形式检验（任务 3.1）

> 脚本：`src/analysis/mapping_check.py`｜产出：`mapping_check_result.csv`
> 被检验对象：`scoring.py:161` 的 `s = 60.0 * P / p_ref` → `round(min(100, max(0, s)))`

## 九、要检验的到底是什么

`scoring.py` 里这一行代码不是从数据拟合出来的，是**手写的参数化假设**。它隐含两条断言：

```
H1 线性:  未截断区内 竞争分 s 与捕获份额 P 成正比（斜率 = 60/P_REF = 150）
H2 无饱和: P 在该区间内都按同一斜率映射（截断前无递减）
```

任务 3.1 就是要问：**这两条能被数据拒绝吗？**

## 十、关键设计：必须先净化样本，否则测的是别的东西

`scoring.py` 有**三条**路径绕过 `s = 150P`：

| 分支 | 条件 | 行为 | 样本数 |
|---|---|---|---|
| (a) 蓝海特例 | `n_comp == 0` | `return 75`，**完全绕过映射式** | 3 |
| (b) 硬截断 | `P > 0.6667` | `min(100, ·)` 压平为 100 | 19 |
| (c) 正常映射 | 其余 | `s = 150P` 生效 | **61** |

**不隔离 (a) 就会测错**：75 是常数，混进来会被当成"映射残差"污染统计量（初版脚本就踩了这个坑，导致高区标准差被虚报成 8.78，实际应为 0）。

隔离后发现一个**得单独说明的现象**：6 家门店 `s = 75`，但只有 3 家是 `n_comp = 0` 的蓝海分支；另外 3 家（`CoCo都可工联CC店 P=0.4997`、`茉莉奶白海宁银泰城店 P=0.4995`、`蜜雪冰城银泰店 P=0.5027`）是 **`150P` 恰好落在 75 附近被 `round()` 取整**，属正常映射。二者数值巧合相同，但性质完全不同。

## 十一、H1 线性假设：✅ 经检验成立（这是本次最硬的结论）

在**未截断子样本**（`P ≤ 0.6667`，n=61）上做参数检验：

```
自由线性拟合   s = a + b·P        （HC3 稳健标准误）
  项        估计      SE(HC3)        t          p            95%CI
  a      0.1200      0.1416       0.848      >0.999     [-0.157, +0.398]
  b    149.7356      0.3450     434.053     <0.001     [+149.059, +150.412]

Wald  H0: b = 150     W = 0.6798   p = 0.4097   → 不拒绝 ✅
Wald  H0: a = 0       W = 0.8190   p = 0.3655   → 不拒绝 ✅

★ 逐点核对: 61/61 家精确等于 round(150·P)
```

**三条证据互相印证**：

1. `b` 的 95% CI `[149.06, 150.41]` **覆盖**现状值 150；
2. Wald 检验不拒绝 `b=150`，也不拒绝 `a=0` → 纯比例、过原点的形式成立；
3. **61/61 逐点精确命中** `round(150P)`——不是"近似成立"，是**零偏离**。

第 3 条比任何拟合优度都硬：它直接排除了对数 / 分段 / 幂等更复杂形式的必要性——**在这段区间它们不可能更好**。

残差分箱同样支持（残差全部来自 `round()` 的量化误差）：

| P 区间 | n | 残差均值 | 残差标准差 |
|---|---|---|---|
| (0.00, 0.35] | 26 | +0.075 | 0.324 |
| (0.35, 0.50] | 23 | −0.069 | 0.283 |
| (0.50, 0.67] | 12 | +0.051 | 0.334 |
| (0.67, 1.01] | 19 | +0.000 | **0.000** |

未截断区三段的残差均值 `|μ| < 0.08`、标准差 `< 0.34` → **线性斜率无系统性偏差**。
截断区残差恒为 0（`s=100` 与 `min(100,150P)=100` 相消），正说明该区已被 `min()` **完全压平、无残差变异可言**。

## 十二、H2 无饱和假设：⚠️ 被拒绝，但"修不了"

**事实**：`P > 0.6667` 的 19 家门店竞争分**全部并列 100，标准差 = 0**。区分度归零。

**然后是一个意外的数学结论**：我原本打算给一个"保持低区不动的软饱和"方案，但**它不存在**。证明：

```
希望同时满足:
  (i)   P = P* 处 s = 100      （与现状连续）
  (ii)  P > P* 处 s 单调不减
  (iii) 恒有 s ≤ 100

但 P* 处 s 已达上界 100。由 (ii)+(iii):
      s(P) ≥ s(P*) = 100  且  s(P) ≤ 100   →   s(P) ≡ 100   (P ≥ P*)

即: 同时满足 (i)(ii)(iii) 的唯一函数是常数 100。
→ "保号软饱和"在数学上不存在。
```

要恢复高区区分度，**必须放弃 (i)**——让 `s` 在 `P*` 之前就不再线性上升。

**方案乙（全程 Hill 软饱和）的实测参数**，参数化使 60 分锚点精确保住：

```
s(P) = 100·P^a / (P^a + c^a),    c = P_REF·((100−60)/60)^(1/a)
→ 任何 a 下 s(0.40) ≡ 60.00（锚点不破）
```

| a | c | s(.20) | s(.40) | s(.667) | s(.85) | s(1.0) | 高区标准差 |
|---|---|---|---|---|---|---|---|
| 1.5 | 0.3053 | 34.65 | **60.00** | 76.35 | 82.29 | 85.57 | 3.268 |
| **2.0** | 0.3266 | 27.27 | **60.00** | 80.65 | 87.14 | 90.36 | 3.443 |
| 3.0 | 0.3494 | 15.79 | **60.00** | 87.41 | 93.50 | 95.91 | 3.003 |
| 4.0 | 0.3614 | 8.57 | **60.00** | 92.05 | 96.83 | 98.32 | 2.202 |

`a = 2.0` 是推荐折中：`P=1.0` 得 90.4 分（头部梯度合理），`s(0.20)=27.3` 与现状 30 差异很小。

## 十三、结构判据（唯一不能被恒等式化的检验）

前两节都是拿 `P` 解释 `s`，而 `s` 是 `P` 的确定性函数——**严格说都不构成经验检验**。唯一干净的检验是：**控制 `P` 后，`P` 之外的变量还有没有增量解释力？**

`own_S`（品牌力）和 `竞品数` 都不进入 `s` 的算式，却是 `P` 的上游，是理想探针：

| 模型 | R² | β_P | p(β_P) | 额外β | p(额外) |
|---|---|---|---|---|---|
| 基准 `s ~ P` | 0.8948 | 104.253 | <0.001 | — | — |
| `+品牌力` | 0.8973 | 104.120 | <0.001 | +2.5433 | >0.999 不显著 |
| `+竞品数` | 0.8970 | 108.337 | <0.001 | +0.1786 | >0.999 不显著 |
| `+两者` | 0.8990 | 107.709 | <0.001 | +2.2770 | >0.999 不显著 |

`ΔR²` 全部 `< 0.005`，额外项全部不显著 → **竞争分的信息全部来自 `P`**，"纯 P 映射"的形式设定得到支持（不必扩项）。

**外部交叉验证**（品牌盲档 `P_anchor`）：`Spearman(s, P_anchor) = +0.8621`，`Spearman(s, P) = +0.9931`。品牌盲口径的排序与竞争分仍高度一致 → **映射形式不依赖品牌口径**，150 这个系数只与"以什么为基准给 60 分"有关。

## 十四、结论与建议

**可写进文档的诚实表述**：

> 「竞争压力映射 `s = 60·P/P_REF` 的**线性形式经检验成立**——在未截断区（`P ≤ 0.6667`，n=61）逐点精确等于 `round(150P)`，Wald 检验不拒绝斜率=150、截距=0。但其**硬截断**（`min(100,·)`）使 19 家（22.9%）门店并列满分、失去区分度；另有蓝海分支（`n_comp=0`）直接给 75 分。两者均为已知设计取舍，非缺陷。」

**是否修改映射式 → 默认建议：不改。** 理由：

1. 低区已**逐点精确**成立，改写会破坏这一已验证的结论；
2. 高区 `s` 无变异，**无从拟合**——高区分度只能靠 `P` 重新生成，属设计决策而非数据发现；
3. 竞争分在总分中权重仅 **0.25**，且高 `P` 门店高度集中在杭州 in77 同一商圈，跨商圈排序基本不受影响；
4. 换 Hill 式会改变 60 分锚点的含义，牵动 `REF_DP`/`P_REF` 整条标定链，且必须与**待修的锚点口径 bug** 一并评估。

**答辩口径（被追问"满分并列怎么办"）**：

> 「竞争压力分采用线性映射 `s = 60·P/P_REF`，在 `P ≤ 0.667` 区间经检验与数据逐点精确一致（61/61），Wald 检验不拒绝斜率=150。在 `P > 0.667` 区间采用满分封顶，导致约 23% 门店并列 100。我们评估过软饱和方案，但已证明"保持低区不变的软饱和"**在数学上不存在**——因为 `P*` 处已达上界 100。改用全程 Hill 软饱和会改变 60 分锚点含义、牵动全部标定，而竞争分权重仅 0.25、头部门店同商圈，收益不足以偿付改模型风险，故保留封顶并作为已知局限说明。」

## 十八、诊断 I：P 测的不是品牌力，是"位置对手有多弱"

### 18.1 回归证据

对 83 家门店做 `P = a + b·D + c·own_S`（HC3 稳健标准误，剔除 n_comp=0 游离点，n=80）：

| 模型 | R² | 关键系数 |
|---|---|---|
| 仅 D | 0.1566 | b = −0.00977, **p = 2.0e−05** |
| 仅 own_S | 0.0171 | c = +0.0539, **p ≈ 1** |
| D + own_S | 0.1761 | D: p = 2.4e−05；**own_S: p ≈ 1** |

**控制住 D（周边密度）之后，`own_S` 对 P 的增量解释力为零。**

> ⚠️ `p ≈ 1` 是 `p_hc3` 在 t≈0 时的截断显示，不是真的 1.000000；
> 读法应为"**远不显著**"，与 R² 仅 0.0171 互相印证。

### 18.2 反事实证据（更有说服力）

直接改 `own_S` 重算 P，看它到底多敏感：

| 门店 | P (own_S=1.0) | P (own_S=2.5) | 变化 |
|---|---|---|---|
| 渝品燕鲜炖热饮 | 0.9626 | 0.9847 | +0.0221 |
| Blue Gaga | 0.8596 | 0.9387 | +0.0791 |
| 熹子茶馆 | 0.6963 | 0.8515 | +0.1552 |
| 南霆茶序(城隍庙店) | 0.3156 | 0.5355 | +0.2199 |

**个体/杂牌 P 中位: 0.7639 → 0.8882**（own_S 1.0→2.5）
**蜜雪冰城 P 中位: 0.6352 → 0.4106**（own_S 2.5→1.0）

机理很清楚：Huff 的 `P = A/(A+B)`。当周边竞品稀疏时 `B→0`，
即使 `A` 很小，`P` 也趋近 1。**杂牌门店多开在老街区/城隍庙/景区边等
竞争稀疏处，于是拿到"高份额"——但那是几乎不存在的市场里的份额。**

⇒ **P 主要是一个"位置竞争密度"的代理变量，不是品牌力度量。**
在这个量上按品牌标定，等于把"该品牌门店恰好开在哪"写进参数。

## 二十、判定：锚点**不**按品牌标定

## 二十一、真正的解法：品牌同商圈溢价 `UPLIFT`

既然商圈效应（69.5%）远大于品牌效应（8.0%），
正确做法是**在商圈内部做品牌比较**，把商圈差异消掉：

```
uplift_b = median over stores of ( DP_store / DP_median(该店所在商圈) )
uplift_shrunk = 1 + w · (uplift_b − 1),   w = n/(n+K),  K = 5
```

含义：`1.0` = 该品牌在其所在商圈处于中位水平；
`1.13` = 同商圈内比中位门店高 13%。

标定前的低证据点清理（`D < 3.0 且 P > 0.80`，命中 6 家）：

## 二十三、锚点口径 bug（必须先修，否则标定无意义）

### 23.1 bug

### 25.2 `brand_price_reference` 的调用不确定性（重要，本次发现的独立 bug）

`score_site` 在 `brand` 非空且未注入 `price_ref` 时，会调用

| 杭州in77 | 蜜雪冰城 | **None** | **None** |
| 杭州in77 | 霸王茶姬 | 20.0 | 2 |

后果：
1. **同一输入多次运行结果不同**（不可复现）—— 严重影响可答辩性；
2. 蜜雪在杭州 in77 拿不到校正价 → 用品类假设 ¥16 →

3. 这解释了一个反直觉现象：**蜜雪冰城在宁波天一因为拿到 ¥7 校正价，

> 单位口径由 [`品牌级公开数据与客单价口径修正.md`](./品牌级公开数据与客单价口径修正.md) 修复。

# Part 4 · 品牌选择卡片流程（任务 D）

> 目标：既然品牌已有独立系数（Part 3），**用户说开奶茶店时就该先问是哪个牌子**，
> 且位置必须在"输入预算"之前，交互形式做成和选商铺一样的卡片。

## 二十八、为什么必须放在预算之前

不是随意的顺序偏好，是**算法依赖**决定的：

```
品牌选择 ──> state['brand'] ──> score_site(brand=...) ──┬─> own_S = BRAND_S[brand]  （竞争分）
                                                       └─> UPLIFT[brand]            （流水溢价）
预算输入 ──> state['investment'] ──> profit 模块（回本周期、三档区间）
```

- 品牌影响**流水**，流水影响**租金承受力**（`s4`），也影响**回本周期**。
- 若先问预算再问品牌，用户给出的预算是按"某个假设品牌"估的；等品牌确定后
  回本周期会凭空跳变，用户会觉得数字不靠谱。
- 所以顺序必须是：**选商铺 → 选品牌 → 报预算 → 出结果**。

## 二十九、数据结构（无新增字段）

`AgentState.brand` 早在 state.py 第 26 行就存在（注释："加盟品牌名（如"蜜雪冰城"）或"自创品牌""），
本次**只做流程接线，不改 schema**：

- 新增阶段 `phase = 'collect_brand'`（位于 `select_shop` 与 `collect_invest` 之间）
- 新增节点 `collect_brand`（仅奶茶品类进入）
- 新增工作台负载 `kind = 'brands'`（由 `build_brand_payload()` 产出）

## 三十、新增节点：`collect_brand_node`

**触发条件**（`_needs_brand_step(state)`）：`category == '奶茶'` 且 `brand` 未设置。

**三条进入路径都必须先经过它**（这是实现时最容易漏的地方）：

| 进入方式 | 原行为 | 新行为 |
|---|---|---|
| `collect_info`（已有具体铺子，信息齐备） | → `collect_invest` | → `collect_brand` |
| `select_shop`（从候选卡片选中铺子） | → `collect_invest` | → `collect_brand` |
| `collect_invest`（兜底：品牌竟未设） | — | → 退回 `collect_brand` |

⚠️ **实现坑**：`collect_info` 分支最初只返回 `{'phase': 'collect_brand'}` 而没有追加
assistant 消息，而图里 `collect_info → collect_brand` 不是边（映射到 `END`），
结果用户发言后**没有任何回复**。修复方式是让该分支自己带上 `brand_ask_message()`。
**规律：凡是通过"返回 phase"改变流程的节点，都要确认该 phase 在路由表里有对应边；
没有边就必须在该节点内自己产出用户可见的回复。**

## 三十一、品牌卡片负载（`build_brand_payload`）

```python
BRAND_PICK_LIMIT = 14      # 保证 9 个已标定品牌一定在列
```

**排序策略（决定用户第一眼看到什么）**：

1. 有同商圈溢价标定的品牌（`UPLIFT` 命中）排前面
2. 组内按 `BRAND_S` 降序
3. 无标定的品牌垫后，标注「暂无标定」
4. 最后追加**自创品牌**逃生项

**为什么不按 `BRAND_S` 单纯降序**：那样 古茗/奈雪/茉酸奶 等 9 个无标定品牌
会混进头部；用户选了它们，品牌维度拿不到任何差异（系数恒 1.0），
卡片等于白给。已标定优先，才是把 Part 3 的成果真正交付给用户。

**卡片字段**：`i / brand / s / uplift / tier / ci / n / invest_ref / yearly_fee / self_created`

## 三十三、实现时发现并修掉的三个真 bug

### 33.1 `collect_info` 静默无回复（见 §三十）
用户说完需求后系统不吭声。属于流程接线缺陷，已修。

### 33.2 `自创品牌` 拿不到承诺的 +6%
卡片写着"按'个体/杂牌'标定，溢价 +6%"，但实测 `溢价系数 = 1.0 / TIER3`。
原因：`scoring.py` 用 `brand_uplift_detail(brand, strict=True)`，
而 `'自创品牌'` 既不是 `UPLIFT` 的 key，也过不了 `brand_attractiveness()`
→ `strict` 模式按"未知品牌"返回 `(None, 1.0)`。

**修复**：在 `brands.py` 加 `_SELF_BRAND_ALIASES`：

```python
_SELF_BRAND_ALIASES = {'自创品牌', '个体/杂牌', '个体', '杂牌', '不加盟', '自营'}
```

放在 `strict` 判断**之前**。关键区分：
- **用户明确选了自创** → 就是标定里的"个体/杂牌"档，`strict=True` 也要给 1.0599
- **识别不出的未知品牌**（错别字）→ 保持中性 1.0

修复后实测：`自创品牌 → 1.0599 / TIER2 / n=7`，与卡片文案一致。

### 33.3 小写英文品牌名识别失败
`BRAND_KEYWORDS['CoCo'] = ['CoCo', '都可']` 是大小写敏感的，用户打 `coco` 识别不出。
已在关键词表补小写别名，并在 `_parse_brand_choice` 加 ASCII 大小写不敏感兜底
（`kw.isascii() and kw.lower() in low`），不影响中文关键词。
