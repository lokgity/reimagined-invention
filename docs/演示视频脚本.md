### ② 全景快览（00:30–00:50）

**画面**：鼠标扫过左侧操作栏（新建对话 / 导出 / 对比分析 / 四个快速演示按钮 / 历史会话 / 知识库）→ 指向右侧工作台

> 让我们直接开始——用一句话发起一次真实的选址分析。"

### ③ 核心演示A：一句话选址全流程（00:50–02:20）

**画面**：输入框输入："我想在杭州武林广场开一家奶茶店，30平米，月租8000，预算20万" → 回车
**旁白**：
> "这是真实存在的商铺场景。注意看——智能体先**理解请求**：自动解析出品类、地点、面积、租金、预算五项关键参数。"

**画面**：点击展开执行过程（think/tool 步骤实时滚动：定位坐标→抓周边POI→评分→盈利测算）
**旁白**：
> "随后是智能体的**决策引擎**。它并行调起多个能力模块：高德地图定位并抓取周边真实POI，58同城核实在租店铺，再交给评分引擎——用Huff引力模型从客群匹配、竞争压力、交通可达、租金承受四个维度打分。"

**画面**：右侧工作台结果展示——指标卡 + 雷达图 + 得分表 + 地图热力图（可放慢鼠标逐块划过）
**旁白**：
> "结果不只是一句'能开不能开'——右侧工作台给出**可解释的评分依据**：每个维度的分数、周边竞品、通勤配套，全部可视化。"

**画面**：回到聊天区，LLM 解读结论 + 盈利测算（月净利 / 回本周期）+ 风险提醒
**旁白**：
> "最后，大模型把复杂数据翻译成人话：结论、理由、盈利测算、风险提醒，一次讲清楚。这才是'决策解释器'——不只给答案，还给证据。"

### ④ 核心演示B：候选商铺卡片选择（02:20–03:20）

**画面**：新对话，输入："我想在宁波开早餐店，帮我找找合适的铺子"（未给具体地址）→ 右侧出现候选商铺卡片列表
**旁白**：
> "如果创业者还没选定铺子呢？智能体自动切换分支——去58同城抓取真实在租店铺，以卡片形式呈现：租金、面积、位置一目了然。"

**画面**：鼠标划过几张卡片（展示在租/出租标签、区域级精度提示）→ 点击其中一张卡片
**旁白**：
> "注意这些卡片来自**真实房源数据**。创业者不用打字，点一下卡片，智能体立即针对这家铺子启动完整分析——候选、选择、分析三个环节无缝衔接，这正是**智能体与数据模块协同**的体现。"

**画面**：分析完成后快速展示右侧工作台评分（不重复展开细节，快进感）
**旁白**：
> "从'我还没想好'到'这家值不值得开'，整个流程不到半分钟。"

### ⑤ 核心演示C：跨会话全方位对比（03:20–04:10）

## 三、录制准备清单（录屏前必做）

1. **清理演示环境**（避免脏数据干扰镜头）：
   - 删除多余的历史会话与历史分析，只保留演示要用的 2-3 个分析记录
   - 刷新浏览器（Ctrl+F5）确保加载最新前端（v=18）
2. **确保 API 可用**：
   - 高德 key 配额充足（演示 A/B 会消耗约 6 次/地址）
   - 大模型 key 余额正常（演示 A 会调用 LLM 生成解读）
   - 备好**备用 key**，防止演示中途失败
3. **录屏设置**：
   - 分辨率 ≥1920×1080，帧率 30fps，MP4（H.264）
   - 浏览器窗口最大化，建议隐藏书签栏
   - 关闭所有无关弹窗/通知/输入法弹窗
4. **演示数据准备**（建议提前跑通一次）：
   - 演示 A：武林广场奶茶案例（真实分析一次，记住流畅路径）
   - 演示 B：宁波早餐店（未给地址 → 出卡片）
   - 演示 C：提前用不同店铺做 2-3 次分析，确保历史库里有可勾选的记录
5. **彩排要点**：
   - 全流程彩排 ≥2 遍，确保每步 <30s 内出结果
   - 若某步等待过长，可后期剪辑掉等待片段（旁白无缝衔接）
   - 全程普通话，语速中等偏慢，咬字清楚
