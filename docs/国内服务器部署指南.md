# 国内轻量服务器部署指南（址南针）

> 为什么换：Render 免费实例在**美国俄勒冈**，58 同城对海外 IP 返回"能打开但没有内容"的页面，
> 抓取必失败（2026-09-23 实测：同一份代码在国内抓杭州/嘉兴/海宁全部成功，在 Render 三条全灭）。
> 换到国内节点后，**国内 IP + 能装浏览器 + 有持久磁盘**三个问题一次解决。

---

## 一、买机器（10 分钟）

| 项 | 选什么 | 为什么 |
|---|---|---|
| 类型 | 阿里云 / 腾讯云 **轻量应用服务器** | 比 ECS/CVM 便宜、自带面板、够用 |
| **地域** | **必须国内**（杭州 / 上海 / 北京 / 广州） | ⭐ 这是本次换机的**唯一目的**：国内 IP 才抓得到 58 |
| 配置 | **2 核 4G 起**（最低 2 核 2G） | Chromium 一个进程就吃 200~400MB，加上 Chainlit + LangGraph，2G 会紧 |
| 系统镜像 | **Ubuntu 24.04 LTS** | ⭐ 自带 **Python 3.12**，和本地一致，省掉装解释器的坑（22.04 是 3.10，要另外装） |
| 带宽 | 3M 起即可 | 只服务评委，不是高并发 |
| 价格 | 学生认证后通常每月十几到几十元 | 以官网当时价为准，我不报具体数 |

## 二、⚠️ 先想清楚域名这件事（**最容易踩的坑**）

**国内节点要绑域名走 80/443，必须 ICP 备案**，个人备案一般 **2~3 周**。
iCAN 截止 10-15 —— **很可能来不及**。

**所以按这个优先级来：**

1. **先用 IP + 端口跑起来**（今晚就能用，零等待）：
   ```
   http://<你的公网IP>:8502
   ```
   把 IP 发给评委即可。缺点：难记、HTTP 明文。

2. **再试"域名 + 非 80/443 端口"**（半小时能验证）：
   ```
   http://compassing.me:8502
   ```
   阿里云/腾讯云对未备案域名的拦截**主要盯 80/443**，其他端口通常是通的。
   ⚠️ 这条**必须实测**：先把域名 A 记录指向新 IP，然后从手机流量访问端口 8502 试一次。
   通了就用它，不通就退回方案 1。

3. **备案**（如果时间够，且你愿意等）：拿证后 80/443 + HTTPS 随便用。
   ⚠️ `compassing.me` 是境外注册的域名，**备案要求域名注册商在工信部白名单内**，
   这点先确认，否则可能得换个 `.cn` / `.com` 域名去备案。

## 三、搬代码与数据

### 代码走 git（不要 scp 整个目录，本地目录有 778M）

```bash
sudo apt update && sudo apt install -y git
git clone <你的仓库地址> /opt/zhinanzhen
cd /opt/zhinanzhen
```

⚠️ **搬之前先统一代码版本**：你和另一个 AI 在并行改这个项目，
线上那份（含"演示模式"闸门）和本地这份**不是同一份**。
**以本地这份为准**（2026-09-23 实测能抓 58、能跑 v8 口径），
把线上那份里你想要的东西**挑出来合并**，别直接覆盖。

### 数据文件要单独搬（约 50MB，git 里没有）

`data/` 被 `.gitignore` 排除了，**必须手动传**，否则选址引擎没有数据：

| 文件 | 大小 | 作用 | 可以不传吗 |
|---|---|---|---|
| `data/zj_poi.db` | 13M | 4.4 万条浙江 POI，**Huff 的需求池全靠它** | ❌ 必须 |
| `data/road_distance.db` | 29M | 步行路网距离，**v8 品牌 uplift 口径依赖** | ❌ 必须 |
| `data/road_path.db` | 88K | 路网路径 | ❌ 必须 |
| `data/tiles/` | 7.2M（401 个文件） | 地图瓦片缓存 | 建议传（不传则首次出图慢） |
| `data/reports/` | 32M | **历史报告，纯属旧产物** | ✅ 不用传 |
| `data/*.json` | ~250K | 会话/分析记录，**建议不传**（从干净的开始） | 可选 |

```bash
# 在你本地电脑上执行（Windows 用 Git Bash / PowerShell 都行）
scp data/zj_poi.db data/road_distance.db data/road_path.db root@<IP>:/opt/zhinanzhen/data/
scp -r data/tiles root@<IP>:/opt/zhinanzhen/data/
```

## 四、装环境（照抄即可）

```bash
cd /opt/zhinanzhen

# 1) 系统依赖
sudo apt install -y python3.12-venv

# 2) 虚拟环境 + Python 依赖
python3.12 -m venv .venv
source .venv/bin/activate
pip install -U pip
pip install -r requirements.txt

# 3) ⭐ 浏览器 + 系统库 —— 这一步在 Render 上永远做不了（没 root、没 apt）
python -m playwright install --with-deps chromium

# 4) ⭐ 中文字体 —— 不装的话地图图例的中文会变成方块
#    （代码里 ImageFont.truetype('msyh.ttc') 是 Windows 字体名，Linux 上会走 except 兜底）
sudo apt install -y fonts-noto-cjk

# 5) 验证环境
python src/analysis/check_deploy_env.py 嘉兴 海宁
```

**第 5 步会直接告诉你成不成** —— 它分三层打印：浏览器能否启动、PC 站、移动端。
（这个脚本是 2026-09-23 为排查 Render 问题写的，正好当部署验收用。）

## 五、配 `.env`

```bash
cp .env.example .env && nano .env     # 填 AMAP_KEY / AMAP_SECRET / LLM_ARK_API_KEY 等
```

⚠️ 四个建议（公网服务的安全底线）：

- `ACCESS_CODE` **设一个**（否则谁拿到 IP 都能刷你的高德和 LLM 额度）；
- `DAILY_BUDGET` 先设小（如 150），跑顺了再调；
- **演示用的高德 key 与 LLM key 另注册一份**，和开发用的物理分开；
- `GATE_DEBUG=0`，需要排查时再开。

## 六、让它常驻（systemd）

```bash
sudo nano /etc/systemd/system/zhinanzhen.service
```

```ini
[Unit]
Description=zhinanzhen (SiteCompass)
After=network.target

[Service]
Type=simple
WorkingDirectory=/opt/zhinanzhen
EnvironmentFile=/opt/zhinanzhen/.env
ExecStart=/opt/zhinanzhen/.venv/bin/chainlit run src/ui/app_chainlit.py --host 0.0.0.0 --port 8502 --headless
Restart=always
RestartSec=5
User=root

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now zhinanzhen
sudo systemctl status zhinanzhen          # 应看到 active (running)
journalctl -u zhinanzhen -f               # 实时看日志
```

**放行端口**（云控制台的"防火墙/安全组"里加规则，**别只改机器里的 ufw**）：

```
TCP 8502  允许  0.0.0.0/0
```

## 七、验收（顺序别跳）

1. **本机能不能连**：`curl -I http://127.0.0.1:8502` → 200
2. **外面能不能连**：手机**关掉 WiFi 用流量**打开 `http://<IP>:8502`（走 WiFi 是内网，测了个寂寞）
3. ⭐ **58 抓取**：在页面上发「我想在杭州滨江开一家奶茶店」→ **应当出现真实候选商铺**
   （而不是"取数失败"）
4. **PDF 导出**：点导出，能下载就是对的（这一步也在验证 Chromium）
5. **地图图例**：看右侧地图上的"● 本铺 / ● 竞品"是不是中文正常（不是方框）

## 八、搬到 Linux 后已知要修的两处（部署完告诉我，我来改）

1. **字体**：`app_chainlit.py:2190` 写死 `ImageFont.truetype('msyh.ttc')`，
   Linux 上会走 `except` 兜底 → **不崩，但地图图例中文变方块**。
   修法：加一条 Linux 字体路径探测（`/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc`）。
2. **抓取失败不打日志**：`fetch_shops` 的失败原因只进 `meta`（渲染成界面文案），
   **服务器日志里看不到** —— 这次排查就卡在这。修法：失败时 `print` 到 stdout。
