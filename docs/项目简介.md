# 址南针 · 项目简介

## 一句话介绍
址南针是一个由大语言模型（LLM）驱动的商铺选址智能体：用户用一句话描述"想开什么店、开在哪里"，系统自动完成"意图理解 → 真实数据抓取 → 科学评分 → 盈利测算 → 口语化结论 → 跨方案对比"的完整决策闭环。

## 项目背景
个体创业者每年有数百万人把积蓄押在"一次选址"上，却普遍缺乏数据工具，只能靠感觉与中介话术做决定，一次失误可能耗尽积蓄。址南针把专业选址决策"普惠化"，让普通创业者像拥有专业顾问一样做出有依据的决策。

## 核心功能
- **一句话选址**：自然语言自动解析品类/地点/租金/面积/预算
- **真实数据**：高德 POI + 58 同城真实在租房源 + 本地库三级联动
- **可解释评分**：Huff 引力模型四维评分（客群/竞争/交通/租金）+ 证据引用
- **盈利测算**：水电/人工/物料/固定成本 → 月净利 → 回本周期
- **跨会话对比**：历史分析勾选 2-4 个，多雷达 + 多列表格对比
- **报告交付**：一键导出 PDF 分析报告

## 技术方案
- 对话界面：Chainlit 2.11
- Agent 编排：LangGraph 多阶段状态图
- 大模型：火山方舟豆包（主）/ 小米 mimo（备）/ DeepSeek（再备），三级降级
- 评分引擎：Huff 引力模型 + 品类画像参数
- 稳定性：三级 LLM 降级 + 数据双兜底，演示零中断

## 创新亮点
1. 对照实验证明"LLM + 规则引擎"协同优于纯 LLM 直接打分（避免高估热门商圈/低估冷门点位）
2. 评分可解释可试算（敏感度测试：租金/半径变动可预测）
3. 面向"素人"创业者的零门槛交互设计

## 商业模式
加盟商选址评估服务 + B 端商圈数据洞察服务（API/报告），兼顾个人增值服务。
